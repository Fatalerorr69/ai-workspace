## 🎯 Úvod

**SuperNastroj v5.0** je profesionální multiplatformní systémový nástroj pro diagnostiku, 
opravu a optimalizaci systémů. Vyvíjeno **FatalErorr69**.

### ✨ Klíčové Vlastnosti
- ✅ **3 platformy**: Windows, Linux, Android/Termux
- ✅ **50+ funkcí**: Kompletní systémová správa
- ✅ **Automatizace**: Inteligentní opravy a diagnostika
- ✅ **Bezpečnost**: Built-in security audity
- ✅ **Profesionální**: Enterprise-ready nástroj

## ✨ Hlavní Funkce

### 🛠️ Windows (SuperNastroj_Complete.bat)
- Rychlá oprava systému (SFC, DISM, CHKDSK)
- Pokročilá diagnostika (6 modulů)
- Boot Disk Creator (Windows/Linux USB)
- Bezpečnost a hardening
- Síťové nástroje (nmap, WiFi)
- Správa disků a zálohy
- Recovery nástroje

### 🐧 Linux (SuperNastroj_linux.sh)
- Systémové opravy a optimalizace
- Hardware diagnostika
- Síťové nástroje a monitoring
- Package management
- Boot a recovery
- Security audity

### 📱 Android (SuperNastroj_android.sh)
- Diagnostika zařízení
- WiFi analýza
- Síťové skenování
- Baterie monitoring
- Termux management
- Security scan

## 🚀 Rychlý Start

### Windows (30 sekund)
```cmd
1. Pravý klik na SuperNastroj_Complete.bat
2. "Spustit jako správce"
3. Vyberte funkci z menu
```

### Linux (30 sekund)
```bash
chmod +x SuperNastroj_launcher.sh
sudo ./SuperNastroj_launcher.sh
```

### Android/Termux (1 minuta)
```bash
pkg update && pkg upgrade
pkg install python nmap curl wget git
chmod +x SuperNastroj_android.sh
./SuperNastroj_android.sh
```
