## Popis z README
# 🚀 Universal AI Development Codespace

Univerzální vývojové prostředí s AI asistenty pro jakýkoli projekt.

## 🎯 Rychlý start

1. **Otevřete Codespace** - Tento repozitář → Code → Codespaces → New codespace
2. **Počkejte na instalaci** - Automaticky se nainstaluje vše potřebné
3. **Začněte používat** - Vše je připraveno!

## 🤖 AI Příkazy

### Základní příkazy:
```bash
ai-help                    # Zobrazit všechny příkazy
ai-chat "tvůj dotaz"      # Chat s AI
ai-code python "úkol"     # Generovat kód
ai-explain soubor.py      # Vysvětlit kód
ai-review soubor.js       # Code review
ai-debug soubor.py "chyba" # Debugování
